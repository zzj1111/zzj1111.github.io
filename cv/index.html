Professional Summary

My research focuses on self-improving LLM agents via reinforcement learning: (1) agentic RL and multi-agent systems for real-world coding tasks such as GPU kernel optimization; (2) recursive self-improvement of the RL post-training loop itself, where the system refines its own scaffolds, rewards, data, and evaluation to keep pushing the capability frontier.

Experience

  • 2025 - Present
    PhD Student
    Mingyi Hong's Lab, University of Minnesota
    Advisor: Prof. Mingyi Hong
    • AutoScaffold (first author, under review): an AI-for-AI framework where a frozen teacher LLM reads the student’s RL training experience, diagnoses its bottlenecks, and writes adaptive scaffolds (class-level strategies and instance-level hints) into the training prompts, with no human intervention. Evaluated without scaffolds, students trained with AutoScaffold outperform the corresponding RL baselines in all four domains (ALFWorld, search-based QA, math reasoning, and GPU kernel generation), e.g., +7.2 points in ALFWorld success rate, and surpass QuestA’s math accuracy with about one-third of the training steps. Joint work with JPMorgan AI Research.
    • Is One Layer Enough? (first author, under review): an empirical study of RL training dynamics in LLMs. Showed that training a single transformer layer can match or surpass full-parameter RL training across seven models, four model families, and three RL algorithms (GRPO, Dr. GRPO, GiGPO). Identified that RL improvements concentrate in middle layers, enabling significant training-cost reduction on mathematical reasoning, code generation, and agentic decision-making tasks.
    • StitchCUDA (co-first author, ICML 2026): a multi-agent workflow for end-to-end CUDA code generation and optimization, enhanced by rubric-based agentic RL. Achieves SOTA in end-to-end CUDA code generation, with a 32B RL-trained model outperforming GPT-5.2, while avoiding reward hacking and significantly reducing rollout overhead by decomposing the coding agent into atomic skills.
    • CudaForge (first author, under review): a simple, effective, and low-cost multi-agent workflow for CUDA kernel generation and optimization. Achieves SOTA on KernelBench Levels 1–3 while costing only $0.3 in API calls and 25 minutes on a single RTX 6000.
    • CUDAHercules (under review): co-developed a benchmark for hardware-aware, expert-level CUDA optimization that evaluates LLMs on real-world GPU programming tasks requiring a deep understanding of hardware architecture.
    • InfantAgent-Next (NeurIPS 2025): contributed to a multimodal generalist agent for computer interaction that modularizes agent workflows, tool selection, and tool execution under a unified dialogue context.
